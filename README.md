# Zero Player Pong

Press `space` to spawn the ball. When the ball bounce from one of the paddles it spawns a new ball. The balls never miss (OR I HOPE THEY DON'T, a rare thing but still a thing. Sometimes it does miss).

You can compile the program by installing SDL3 in your system and your favourite C compiler.

If you are using Linux, after installing `clang`, `SDL3` and `pkg-config`, you should be able to run the program using the helper `run.sh` script provided

If you are using Mac (Linux is better), you should also be okay with the `run.sh` script after you are done installing `SDL3`, `clang` and `pkg-config`

If you are using Windows (fuck you), learn how to compile C code and link libraries in your operating system.
